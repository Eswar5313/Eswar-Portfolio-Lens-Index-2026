## How to navigate
1. **Dashboard** — `index.html` (or the GitHub Pages link above): KPI band, search box, track chips and tag chips.
2. **Track page** — each track folder has its own `index.html` + `README.md` table.
3. **Project page** — each project folder has `index.html`, `README.md`, `FILES_TO_ADD.md` and six sub-folders: `report/ workbook/ presentation/ code/ data/ screenshots/`.
4. `projects.json` — machine-readable registry of everything (used to regenerate the pages).

## Standards that run through every project
- **Verified figures only** — a number is printed only when it is traceable to a source file in the folder.
- **Declared substitutions** — wherever a real dataset could not be used, the synthetic or substituted data is labelled as such inside the deliverable.
- **AI partnership disclosed** — Claude was used for structuring, drafting and code review; analysis, decisions, interviews and submissions are mine.
- **Zero-white-space documents** — reports and decks are measured, not eyeballed, for page fill.
- **Defensive security only** — all cyber-security work targets self-contained lab environments or declared-synthetic data.
